# CAT (third-party, not redistributed)

Clone the original CAT code here:

    git clone https://github.com/Jieerbobo/CAT "Reference code/CAT"
    cp protocol/src/e5_cat_hardneg.py "Reference code/CAT/code/"

CAT ships the Epinions data used as the main benchmark (`data/Epinions`) and its metapath2vec
embeddings (`code/uitiu_*_emb_meta_64.txt`). CAT checkpoints are written to `Reference code/CAT/models/`.
