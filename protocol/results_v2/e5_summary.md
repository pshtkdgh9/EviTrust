## 5. 실행 환경 / 참고

- 환경 `cat_e5` (Windows에 새로 만듦): Python 3.10, torch 2.3.0+cu121, torch-geometric 2.5.1, pyg-lib 0.4.0, torch-scatter 2.1.2, torch-sparse 0.6.18, dgl 2.2.1+cu121, torchdata 0.7.1. ICDE/02_cat_hardneg_run.md §2의 버전(torch 2.0.0 / pyg-lib 0.2.0 / dgl 2.1.0)과 다름. torch 2.2 이하용 pyg-lib Windows 빌드가 없고, LinkNeighborLoader의 시간순(disjoint) 샘플링에는 pyg-lib가 필수이기 때문.
- `e5_cat_hardneg.py`: `C.get_ori_graph(args)` 바로 뒤에 `item_type = item_type.long()` 한 줄 추가 (Windows의 numpy<2는 int32를 만들고 torch_scatter는 int64 인덱스만 받음). `protocol/src/`와 `Reference code/CAT/code/` 두 복사본에 모두 적용. CAT_main.py / CAT_model.py는 수정하지 않음.
- `c_twohop 대체 표본 비율` = 해당 음성 집합에서 2-hop 후보가 부족해 대체 샘플링으로 채운 음성의 비율 (JSON의 `fallback` 값).
